# Imagen del inicio

El FXML de inicio incluye la imagen directamente con `ImageView` y `Image`.

Ruta del recurso:
`src/main/resources/donadores/pe/upeu/visa_shoes_project/images/fondo-zapateria.jpg`

Referencia relativa desde `views/home-view.fxml`:
`@../images/fondo-zapateria.jpg`

Para cambiarla, reemplaza el archivo manteniendo el mismo nombre. No se necesita una clase Java para cargarla.

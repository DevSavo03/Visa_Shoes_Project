# Recursos visuales

Las vistas FXML están en `src/main/resources/donadores/pe/upeu/visa_shoes_project/views/`, y el tema compartido en `css/style.css`.

El inicio inserta la imagen desde `views/home-view.fxml` usando `ImageView` y la ruta relativa `@../images/fondo-zapateria.jpg`. El archivo está en `images/fondo-zapateria.jpg`. Para cambiarlo, reemplaza el archivo conservando ese nombre; no se necesita agregar una clase Java.

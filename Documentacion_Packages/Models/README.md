# Paquete Models

**Paquete Java:** `donadores.pe.upeu.visa_shoes_project.Models`

Contiene las entidades que representan los datos de la zapatería:

- `Persona`: datos personales compartidos.
- `Cliente`: persona con dirección y correo.
- `Producto`: modelo, marca, talla, precio y stock.
- `Venta`: fecha, total, ID/nombre del cliente y lista de detalles.
- `DetalleVenta`: producto, cantidad, precio unitario e importe.

Las propiedades JavaFX permiten enlazar los valores de los modelos con las tablas de las vistas.
